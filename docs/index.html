Celular Android

App com VR (Cardboard), câmera e mãos

⬇ Baixar o app APK · 12,5 MB
  1. Toque em Baixar o app. Se o Chrome avisar que o arquivo pode ser perigoso, toque em Baixar mesmo assim (é o Ryan VR).
  2. Abra o arquivo RyanVR.apk. Se o celular perguntar, permita instalar apps desta fonte.
  3. Toque em Instalar (ou Atualizar, se já tiver o Ryan VR).
  4. Abra o app e permita a câmera para usar as mãos.

iPhone não instala APK: use o botão Jogar no navegador no Safari.

Computador

Mouse para olhar, clique para apertar, teclado para digitar

▶ Jogar no navegador sem instalar ⬇ Baixar para o computador .zip · 0,2 MB
  1. Na tela de entrada, escolha 🖥️ Modo Computador.
  2. Arraste o mouse para olhar em volta e clique para apertar.
  3. No Google, digite no teclado. Esc pausa e sai dos jogos; na Corrida use ← → e espaço.
  4. Baixou o .zip? Descompacte e abra Abrir Ryan VR.html no Chrome.

Precisa de internet. Funciona melhor no Google Chrome ou no Microsoft Edge.

Feito para o Ryan · os jogos e vídeos não enviam nada seu para a internet.
