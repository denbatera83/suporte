# Fuga dos Dinos

Site separado (não faz parte do Ryan VR): um jogo original em que um dinossauro gigante corre atrás de você numa trilha na selva.

- **Com a câmera** (computador ou celular apoiado, virado para você, vendo você de corpo inteiro): **corra no lugar** para correr no jogo (a câmera conta os passos pelos pés, ou pelos joelhos), **pule de verdade** para pular os troncos e **dê um passo para o lado** para trocar de pista e desviar das pedras. No canto aparece a imagem da câmera com as suas pernas desenhadas.
- **Sem câmera:** segure ↑ (ou W) para correr, ← → para trocar de pista, espaço para pular; no celular, toque rápido no botão laranja e use as setas.
- Pegue ovos (+10). Bateu num tronco ou pedra, você tropeça e o dino chega mais perto. Se ele te alcançar, acaba. Recorde salvo no aparelho.
- O reconhecimento do corpo usa o MediaPipe Pose (Google), direto no aparelho: nada da câmera é enviado.
